# GameVault: PWA-приложение

Референс: [MooWin Casino Lobby (Neomodeon, Dribbble)](https://dribbble.com/shots/25336477-MooWin-Casino-Crash-game-Lobby-page).

## Экраны
1. **Главная**: баннер «Игра недели», задания, популярное, жанры, новинки
2. **Игры (каталог)**: поиск и жанры
3. **Страница игры**: рейтинг, описание, «Играть», «в избранное», «поделиться», похожие игры
4. **Избранное**: сохранённые игры (хранятся в localStorage)
5. **Аркада**: мини-игра «Поймай звезду», за очки начисляются монеты
6. **Профиль**: аватар, имя, уровень, достижения, язык, кнопка «Установить»

## Адаптив
- телефон (до 900px): нижнее меню
- планшет и ноутбук (от 900px): боковое меню и поиск сверху
- широкий экран (от 1280px): справа ещё ежедневный бонус, рейтинг игроков и задания

## Языки
Английский и русский. При первом запуске язык берётся из настроек телефона или браузера:
русский для ru/be/kk, иначе английский. Переключатель есть в меню и в профиле, выбор запоминается.
Все тексты лежат в объекте `I18N` в начале `app.js`.

## Картинки игр
Лежат в `img/`. Чтобы поставить картинку игре, впиши в `GAMES` (в `app.js`) поле `img: 'img/имя.png'`.
Если картинки нет, обложка рисуется автоматически: градиент, название и эмодзи.
После замены файлов поменяй `CACHE` в `sw.js` (например, `gamevault-v3`), иначе телефон покажет старую версию из кэша.

## Что делает его PWA
- `manifest.webmanifest`: название, иконки, цвет, `display: standalone` (открывается без адресной строки, как обычное приложение)
- `sw.js`: service worker, кэширует файлы, поэтому приложение открывается без интернета
- `icons/`: иконки 192 и 512 px, обычные и maskable (под круглые и прочие иконки Android)

## Запуск на Mac
```
cd ~/Desktop/game-pwa
python3 -m http.server 8765
```
Затем открыть http://localhost:8765

## Публикация (нужен HTTPS, иначе Android не предложит установку)
**GitHub Pages, без терминала:**
1. github.com → New repository → имя `game-pwa`, Public → Create
2. «uploading an existing file» → перетащить ВСЁ содержимое папки (вместе с папкой `icons`) → Commit
3. Settings → Pages → Branch: `main`, папка `/ (root)` → Save
4. Через 1–2 минуты сайт будет по адресу `https://ИМЯ.github.io/game-pwa/`

## Установка на Android
1. Открыть ссылку в **Chrome** на телефоне
2. Профиль → «Установить на экран», или меню ⋮ → «Установить приложение» / «Добавить на главный экран»
3. Иконка GameVault появится на рабочем столе и откроется в отдельном окне
